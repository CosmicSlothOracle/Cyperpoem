Cyber Steps Analysis – Part 2

Evidence-based single-host reconnaissance report. Target: scanme.cybersteps.de

Methodology and Discovery

Classification: Authorized lab assessment
Scope: Single host only (no exploitation, no authentication bypass attempts). Covers observations from active and passive reconnaissance.

Findings are limited to observed data. Risk assessments describe plausible impact based on confirmed evidence; conditional language is used where configuration or auth state was not verified.

Initial Findings

  • Passive recon: Target identified via subfinder (careerportal, ai-challenge, chat). DNS TTL of 300 seconds was observed; a relatively low TTL may indicate infrastructure designed for operational flexibility, load balancing, or rapid DNS updates.
  • TCP sweep: Primary port scan via naabu (SYN scan, moderate rate) identified 5 open ports: 21, 22, 80, 1080, 3389.
  • UDP sweep: Most ports returned open|filtered due to no response. Port 520 was confirmed closed (ICMP port-unreachable).

Service Enumeration and Analysis

Following discovery, service-aware verification was performed on confirmed open TCP ports using custom async Python probes and targeted nmap fingerprinting.

21/tcp FTP

Exposure: Internet-facing Version: Outdated Assessed risk: High Detection confidence: High

Banner / Version

220 ProFTPD 1.2.10

Evidence

"port": 21, "open": true, "banner": "220 ProFTPD 1.2.10"

Assessment

Legacy plaintext file transfer is exposed to the internet. ProFTPD 1.2.10 is an ancient release (~2004) with numerous publicly documented critical vulnerabilities (e.g., CVE-2015-3306). The outdated version significantly increases the likelihood of exploitable weaknesses if insecure configurations are present. Anonymous authentication was not tested; if anonymous login is enabled, the service could expose sensitive data or enable unauthorized file transfer.

1080/tcp SOCKS5 Proxy

Exposure: Internet-facing Authentication: Username/password required Assessed risk: Medium Detection confidence: Moderate

Service Characteristics

Auth-gated (Method 0x02 confirmed)

Evidence

1080/tcp open socks | socks-auth-info: Username and password

Assessment

SOCKS5 proxy is exposed to the internet. Protocol and username/password authentication (method 0x02) were confirmed via NSE and handshake negotiation. Credential strength was not tested; if weak or reused credentials are in use, the service could serve as a pivot point for lateral movement.

3389/tcp RDP

Exposure: Internet-facing Access control: No VPN observed Assessed risk: High Detection confidence: High

Service Characteristics

ms-wbt-server

Evidence

"protocol_check":"rdp", "matched":true,
"raw_response_hex":"030000130ed0000012340002..."

Assessment

Remote Desktop Protocol is exposed to the public internet. Service presence was confirmed via a binary TPKT/X.224-style connection response. Internet-facing RDP may be susceptible to brute-force and credential-stuffing attacks. Exposure should ideally be restricted through VPN access controls, IP allowlisting, or MFA enforcement.
