# Bug Bounty Policy Summary

**Company:** GitHub
**Policy URL:** https://bounty.github.com/

**3a (In scope):** GitHub-listed assets only (e.g., `github.com` in-scope subdomains, `githubusercontent.com`, `githubapp.com`, npm domains, GitHub products like Actions/Desktop/Mobile/CLI, Enterprise).

**3b (Out of scope / not allowed):** Non-listed domains, third-party hosted assets, social engineering/phishing/physical attacks, harmful traffic (DDoS/spam/excessive scanning), testing that impacts other users, unnecessary PII access.

**3c (How to report):** Submit via HackerOne (`https://hackerone.com/github`) with clear written repro steps; keep details private until fix/public disclosure window.

**3d (Rewards):** Yes. Bounties are severity-based (about `$617` low to `$30,000+` critical); payout depends on impact, exploitability, scope, and overall risk.

**5 (Why read policy first):** It defines legal/technical boundaries, protects users/systems, keeps research ethical, and avoids account/legal trouble or reward disqualification.
