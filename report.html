1. Executive Summary

Purpose

This report provides a corrected assessment of 165.232.131.154 based on original lab evidence. The original report contained contradictions, misidentified services, and inconsistent ratings. This version restores integrity.

Overall Posture

The host contains two critical vulnerabilities (outdated FTP with anonymous access, and SMTP authentication bypass) leading to info disclosure, DoS, and authenticated abuse. Internet-facing RDP and SNMP increase attack surface. HTTP behaves as a catch-all honeypot. Not suitable for production.

Key Findings

  • FTP (TCP/21) – ProFTPD 1.2.10 (~2005). Anonymous login enabled. Multiple CVEs (directory traversal, DoS, priv esc). [CRITICAL]
  • SMTP (TCP/25) – Auth bypass (235 Authentication successful without creds). No TLS. [CRITICAL]
  • RDP (TCP/3389) – Exposed. Standard TPKT/X.224 response. Brute-force surface. [HIGH]
  • SNMP (UDP/161) – Exposed; potential info disclosure. [HIGH] (if default strings).
  • SOCKS (TCP/1080) – SOCKS5 with user/pass auth (method 0x02). Credential strength unknown. [MEDIUM]
  • HTTP (TCP/80) – No TLS, missing headers, catch-all page (honeypot/SPA). [MEDIUM]
  • SSH (TCP/22) – OpenSSH 8.9p1. Password auth enabled. Weak HMAC-SHA1 offered. [LOW]
  • VNC (TCP/5900) – Detected (protocol 3.8). No auth observed. [LOW]
  • Port 9200 – Filtered. Not confirmed false positive. [INFO]
  • Ports 1433, 1521, 9100 – Closed. [INFO]

NOTE: Out of Scope / Unverified

  • SOCKS credentials were not brute-forced.
  • SMTP relay to external domains is blocked; risk is auth bypass itself.
  • Port 9200 remains indeterminate.
  • No secrets discovered by TruffleHog (scan too short; re-run recommended).

2. Scope & Methodology

In Scope: Single host 165.232.131.154. TCP/UDP scanning, banner grabbing, protocol verification, nuclei, ffuf, trufflehog. No exploitation/auth bypass attempts (except passive SMTP AUTH).

Methodology: OWASP WSTG aligned. Tools: Nmap, naabu, ffuf, nuclei, custom probes. Evidence re-examined.

Limitations: HTTP returns 200 OK for all paths (prevents dir enum). SOCKS5 handshake verification failed (possible honeypot). TruffleHog scan was local cache only.

4. Hardening & Remediation

P0 – IMMEDIATE (Stop active breaches)

  • Disable FTP entirely or replace with SFTP/FTPS. Remove anonymous access.
  • Fix SMTP authentication – require valid credentials. Enforce STARTTLS.
  • Restrict RDP – place behind VPN or IP allowlist; enable NLA.

P1 – HIGH-RISK SURFACES

  • Disable SNMP or change community strings / restrict IPs.
  • Harden SOCKS proxy – rotate credentials, monitor logs.
  • Add TLS to HTTP – enforce HTTPS, add HSTS, CSP, X-Frame-Options.

P2/P3 – DEFENCE-IN-DEPTH & OPS

  • Remove weak SSH MACs from sshd_config.
  • Investigate port 9200 and disable VNC if unused.
  • Enable auth failure logs; repeat remote secrets scanning.
