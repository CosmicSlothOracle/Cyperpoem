1. Executive Summary

Purpose

This report presents the security posture assessment of 165.232.131.154 (scanme.cybersteps.de). Through rigorous active and passive reconnaissance, we evaluated service vulnerability configurations to map the exposure vector of the host.

Overall Posture

The host displays two critical vulnerability vectors: legacy FTP (ProFTPD 1.2.10) configured with anonymous read/write permissions, and an unauthenticated SMTP service exhibiting complete authentication bypass. Additionally, internet-exposed administrative interfaces (RDP, SNMP) and unencrypted web infrastructure (HTTP) significantly broaden the system's attack profile. Immediate mitigation is recommended prior to production deployment.

Consolidated Findings

  • F-01: ProFTPD 1.2.10 (TCP/21) – Legacy release (~2005) with anonymous login active. Vulnerable to remote code execution, directory traversal, and DoS. [CRITICAL]
  • F-02: SMTP Auth Bypass (TCP/25) – Mail server allows unauthenticated session elevation (returns success 235 without credentials). [CRITICAL]
  • F-03: Exposed RDP (TCP/3389) – Remote Desktop fully exposed with default handshakes. Highly susceptible to brute-force vectors. [HIGH]
  • F-04: Exposed SNMP (UDP/161) – Active community string interface allowing environment layout extraction. [HIGH]
  • F-05: SOCKS5 Proxy (TCP/1080) – SOCKS5 handshake negotiates username/password authorization (Method 0x02). Actively serves as potential pivoting target. [MEDIUM]
  • F-06: HTTP No TLS (TCP/80) – Web engine running outdated Apache 2.4.6 with default directory catch-all login behaviour. [MEDIUM]
  • F-07: SSH Weak MACs (TCP/22) – Active OpenSSH service supporting outdated and vulnerable HMAC-SHA1 suites. [LOW]
  • F-08: Unauthenticated VNC (TCP/5900) – VNC RFB 3.8 protocol listening with no credential barriers detected on handshake. [LOW]
  • F-09: Filtered Port 9200 – Indeterminate state (filtered). Needs targeted API probes to differentiate from honeypot. [INFO]
  • F-10: Inactive Standard Ports – Database and printer ports (1433, 1521, 9100) verified closed. [INFO]

2. Scope & Methodology

Methodology: Following the OWASP Web Security Testing Guide (WSTG) and NIST standards, we executed extensive non-intrusive TCP/UDP scanning, banner enumeration, protocol-level checking, and passive DNS mapping. No host exploitation or destructive vulnerability execution was performed.

4.2 Python Custom Banner Prober

import asyncio
import json

TARGET = "165.232.131.154"
PORTS = [21, 22, 80, 1080, 3389]

async def probe(port: int):
    result = {"port": port, "open": False, "banner": ""}
    try:
        reader, writer = await asyncio.wait_for(asyncio.open_connection(TARGET, port), timeout=4)
        result["open"] = True
        probes = [b"", b"HEAD / HTTP/1.0\r\nHost: scanme.cybersteps.de\r\n\r\n", b"\r\n"]
        data = b""
        for p in probes:
            if p:
                writer.write(p)
                await writer.drain()
            try:
                chunk = await asyncio.wait_for(reader.read(1024), timeout=3)
            except Exception:
                chunk = b""
            if chunk:
                data = chunk
                break
        writer.close()
        await writer.wait_closed()
        if data:
            result["banner"] = data.decode("utf-8", errors="replace").strip()
    except Exception:
        pass
    return result

async def main():
    results = await asyncio.gather(*[probe(p) for p in PORTS])
    print(json.dumps(results, indent=2))

if __name__ == "__main__":
    asyncio.run(main())

5. Hardening & Action Items

Priority P0 – Critical Interventions

  • SMTP service: Patch authentication logic to prevent unauthenticated session acceptance (success status code 235).
  • FTP service: Disable anonymous write and read permissions immediately. Upgrade ProFTPD from legacy v1.2.10.
  • RDP exposure: Enforce active IP allowlisting or deploy a VPN gateway to shield port 3389.

Priority P1 – High Surface Interventions

  • SNMP service: Disable public interface accessibility or completely rotate defaults.
  • SOCKS proxy: Relocate proxy entry gate behind trusted VPN context.
